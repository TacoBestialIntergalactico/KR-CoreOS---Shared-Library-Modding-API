# KR CoreOS — Location Groups Reference

Full map of every location group and the exact `ProceduralDistributions.list` containers it expands to. A *group* is a named list of real in-game containers sorted by theme, so you write `MEDICAL = 0.3` instead of naming containers by hand.

- **40 thematic groups** + `OTHER` + **7 combos**, covering **all 1418 loot containers**.
- Auto-generated by `tools/generate_groups.py` and verified against the game's `ProceduralDistributions.lua`. Names absent in the running build are skipped silently.
- The 18 groups at the top are the original curated set; the rest are full-coverage categories.

## Overview — combos

| Combo | Expands to | Notes |
|---|---|---|
| `POWER` | `ELECTRONIC` + `MECHANIC` | Electronics + mechanic shops: everything power-, battery- and appliance-related (ideal for KR SolarOS) |
| `TACTICAL` | `MILITARY` + `SURVIVAL` | Military + survival: field gear (ideal for KR TacticalOS) |
| `COLD_STORAGE` | `FRIDGE` + `FREEZER` | Fridges + freezers: all cold storage (ideal for KR FoodOS) |
| `COOKING` | `KITCHEN` + `STOVE` | Kitchens + stoves: the whole cooking environment |
| `WARZONE` | `MILITARY` + `FIREARMS` + `WEAPONS` + `AMMO` | Full military looting: bases, guns, melee weapons and ammo (ideal for KR TacticalOS) |
| `FOOD` | `GROCERY` + `FRIDGE` + `FREEZER` | All food storage: groceries plus cold storage (ideal for KR FoodOS) |
| `WORKSHOP` | `INDUSTRIAL` + `MECHANIC` + `MATERIALS` | Tools, auto parts and building materials (ideal for crafting/tool mods) |
